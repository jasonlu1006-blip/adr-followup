# ADR follow-up discussion workspace

Encrypted static research discussion site. Contains study planning, cohort availability, longitudinal clinical and radiographic review, and local encrypted measurement drafts.

Only the static application shell and AES-256-GCM encrypted data/assets are published. There is no plaintext patient dataset, credential, DICOM or original spreadsheet in this repository. Authentication is password-derived decryption, not server-side access control. No external JavaScript, analytics or font requests are used.

The current material is authorized virtual data. Measurements, eligibility and clinical endpoints remain subject to source verification. The site shows snapshot coverage and missingness rather than invented results. Browser drafts do not sync to GitHub.
